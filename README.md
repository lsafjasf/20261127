# RGB → XYZ 矩阵可逆性、手性与白点检查

这是一个只使用 Go 标准库的示例模块，用来诊断线性 RGB→XYZ 矩阵：

- 可逆性：用尺度相关的 `|det(M)|` 阈值拒绝奇异或数值不稳定矩阵，并检查 `M·M⁻¹` 往返误差。
- 手性：`det(M) > 0` 为右手系，`det(M) < 0` 为左手系（方向翻转）。
- 白点：默认检查 `M·(1,1,1)` 是否等于 D65 XYZ，同时报告 XYZ 与 `x,y` 色度误差。
- 轴探针：逐轴发送 `+e_R/-e_R`、`+e_G/-e_G`、`+e_B/-e_B`，与预期矩阵比较以定位反号轴。
- 修复：仅反转被探针定位的列，再重新执行全部检查。
- 精度回归：对线性 RGB 样本计算 CIE76 `ΔE` 和 XYZ 欧氏误差，验证修复前后相对同一参考矩阵的误差统计完全一致。

矩阵按行主序存储，颜色向量按列向量参与 `XYZ = M·RGB`。

## 重要边界

RGB→XYZ 的 3×3 矩阵只改变颜色坐标，**本身不会把文字或图像在空间上镜像**。负行列式表示颜色基的手性翻转，不等于像素几何翻转。若文字确实被镜像，应检查这个矩阵是否被误用于顶点、纹理坐标、屏幕/投影等几何变换；仅修颜色矩阵不能解释或修复空间镜像。

## 运行

```bash
go test ./...
go run ./cmd/colorcheck
```

默认示例的“原始矩阵”是 sRGB/D65 矩阵的五位小数近似：

```text
0.41246 0.35758 0.18044
0.21267 0.71516 0.07218
0.01933 0.11919 0.95030
```

故障矩阵把第三列（B 轴）整体取反，因此 `det` 变为负值：

```text
0.41246  0.35758 -0.18044
0.21267  0.71516 -0.07218
0.01933  0.11919 -0.95030
```

示例输出中的关键结果：

```text
输入: det = -0.207077484341, left-handed, B 轴 polarity=flipped
修复: det = +0.207077484341, right-handed, 全部检查通过
原始矩阵色差: max ΔE76 = 0.00426425
修复矩阵色差: max ΔE76 = 0.00426425 (preserved=true)
最小反例: #000001
```

也可以传入自己的 9 个行主序数值：

```bash
go run ./cmd/colorcheck \
  -matrix "0.41246,0.35758,-0.18044,0.21267,0.71516,-0.07218,0.01933,0.11919,-0.95030" \
  -original "0.41246,0.35758,0.18044,0.21267,0.71516,0.07218,0.01933,0.11919,0.95030" \
  -reference "0.4124564,0.3575761,0.1804375,0.2126729,0.7151522,0.0721750,0.0193339,0.1191920,0.9503041"
```

`-white` 可覆盖默认 D65 XYZ。`-original` 是符号正确的目标矩阵，`-reference` 是用于色差统计的颜色学参考矩阵；两者可以相同，也可以不同。

## API

```go
original := rgbxyz.SRGBToXYZD65()
faulty, _ := rgbxyz.FlipColumn(original, 2)

cfg := rgbxyz.DefaultConfig()
cfg.Reference = &original

report := rgbxyz.DiagnoseWithConfig(faulty, cfg)
repaired, final, err := rgbxyz.Repair(faulty, cfg)
```

若没有参考矩阵，可设置 `cfg.Reference = nil`。此时仍会检查手性和白点，修复阶段会尝试三种单列反转并选择白点误差最小且恢复右手系的候选。

`FindMinimalCounterexample` 按 L1 距离从黑到白搜索 8 位线性 RGB，返回第一个超过 `ΔE` 阈值的颜色（同距离按 R、G、B 字典序）。

## 最小反例颜色

对上述“B 列反号”故障，最小 8 位线性 RGB 反例是：

```text
#000001, 即 RGB8(0, 0, 1)
归一化线性 RGB: (0, 0, 1/255)
```

对应的完整基向量 `(0,0,1)`（`#0000FF`）也必然复现，但 `#000001` 是量化网格上距离黑色最近的反例。该反例的故障/修复输出关于原点对称，示例中 `ΔE76 = 10.4309`。
