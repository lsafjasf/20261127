# Exposure Lab

摄影曝光伪色分析工具。Go 标准库提供本地 HTTP 服务，浏览器端以线性光完成分带与裁切分析，不依赖 Node、数据库或第三方 Go 包。

## 运行

```bash
go run .
```

打开 <http://127.0.0.1:8080>。可用 `-addr` 或 `EXPOSURE_ADDR` 修改监听地址：

```bash
go run . -addr 127.0.0.1:9000
```

## 分析语义

- 以画面中的已知 18% 灰卡为锚点，按相对曝光值分为 1 EV 色带；参考灰位于 `EV 0` 色带中央。
- 线性亮度计算使用 sRGB 解码后的 `0.2126 R + 0.7152 G + 0.0722 B`。
- 任一通道达到 250/255 时标记为通道裁切；像素读数、全图统计与画面斜纹分别呈现 R/G/B 状态。
- 明亮连通域按面积、包围盒与填充率再分类：
  - 小而孤立、细长或环形的区域归为镜面高光，以白心和青色边缘显示。
  - 连续、成片且填充度高的区域归为局部过曝，以橙色斜纹和轮廓显示，并标出区域编号与峰值 EV。
- 指针悬停显示 EV、色带、线性亮度、RGB 和裁切通道；底部色阶同步移动数值指针。

## 交互

- 拖动“曝光参考偏移”立即重算伪色图，无需重新上传。
- “拾取参考灰”后在画面中单击，可用 5×5 平均重新锚定参考点。
- “对照”模式下左半为原图、右半为伪色图；叠加层可独立开关。
- 支持 PNG、JPEG、WebP 上传与拖放，分析始终在本地浏览器完成。

## 验证

```bash
go test ./...
go vet ./...
```

测试会校验内置样片的参考灰中性、18% 目标亮度以及亮窗裁切区域。
