## 立体声单声道兼容检查

`monocheck` 是一个无第三方依赖的 Go CLI，用于检查立体声 WAV 折叠为 `(L+R)/2` 后是否出现中置/人声频段的反相抵消。它同时输出时间区间和可复核的声道证据，避免把正常宽声场误报为故障。

### 用法

```bash
go build -o monocheck .
./monocheck --format json input.wav
./monocheck input.wav
```

可选参数：

- `--window N`：FFT 窗长，默认按采样率自动选择，最小 1024，必须是 2 的幂。
- `--hop N`：帧移，默认窗长的一半。
- `--format text|json`：默认 `text`，自动化流程建议使用 `json`。

支持立体声 PCM 8/16/24/32-bit 与 32-bit IEEE float WAV。

### 判定方法

每个分析帧同时计算：

- 左右 RMS 与折叠单声道 RMS，得到整体抵消分贝。
- 左右时域 Pearson 相关度，强反相通常接近 -1。
- `S/M` 边/中信号比，确认侧信号异常压过中信号。
- 人声范围 200 Hz–4 kHz 的互谱相位、平均相干性和频段抵消率。
- 125 Hz–16 kHz 分频段抵消率，用于定位具体频率证据。

只有同时满足明显单声道能量损失、人声频段高抵消、近 ±180° 相位、足够相干性、负相关和高 `S/M` 才会形成故障段。仅左右内容不同、相位约 90°、或普通宽声场不会单独触发。

JSON 中的 `segments` 按严重度排序，最多输出 5 段；每段包含起止秒、最差帧、左右 dBFS、单声道 dBFS、抵消 dB、相关度、人声相位/相干性和分频段抵消率。

### 验证

```bash
go test ./... -cover
go vet ./...
```

测试包含合成反相中心内容、正常宽声场、90° 相位声像、故障时段定位和 WAV 解码。
